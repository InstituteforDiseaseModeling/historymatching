# Instructions

## Via Makefile

1. `make clean` - removes all existing iterations and outputs
2. `make example` - recreates outputs for 2 iterations (0..2)

## Manual

In `iter0` directory:

1. Run `python3 generate_samples_and_results.py`
2. Run `python3 bhm.py`
3. Run `python3 cut.py`

Repeat for `iter1` and `iter2` directories.
