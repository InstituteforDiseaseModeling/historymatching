

                      SIR Tao-Leap Calibration Example


 - To run a calibration job, configure parameters in the 
   sir_tao_leap_calibration.py script and run: 

       python3  sir_tao_leap_calibration.py


 - For trajectory selection, configure parameters in the 
   sir_tao_leap_trajectorySelection.py script and run:   

       python3  sir_tao_leap_trajectorySelection.py


 - Other figures in 
   https://github.com/InstituteforDiseaseModeling/transGenEpi/tree/master/seattleFluSimulatedData
   were generated using the script  displayResults.py


 - Auxiliary functions/scripts for simulation and calibration in this example:

    checkConvergence.py 
    getObservations.py
    runModel.py
    sampleObservations.py
    sampleParameters.py
    sirTaoLeap


 - Auxiliary functions for visualization:

    dataframePlot.py
    historyPlot.py
